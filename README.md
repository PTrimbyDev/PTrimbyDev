# Paul Trimby

**Independent software developer building practical desktop, privacy, governance, data and AI-focused software.**

I build software from concept through to working desktop applications, with a focus on useful products, clear architecture, privacy-conscious design and practical user experiences.

## Current Projects

### Praesera

**Praesera** is a private desktop workspace for operational AI governance, risk and compliance.

It is built around structured relationships between AI systems, risks, controls, evidence and actions, with an emphasis on traceability, explainable governance and practical operational workflows.

Built with React, TypeScript, Tauri, Rust and SQLite.

Development is private. Public material is limited to controlled product information.

### RegulaLearn

**RegulaLearn** is a desktop-first regulatory decision-training application built around fictional workplace scenarios, learner decisions, reasoned feedback and traceability to authoritative sources.

The current module is **Privacy & Data Protection**. The current **Evaluation build** contains 10 learner-facing scenarios and is built with React, TypeScript, Tauri and Rust. Learner progress is stored locally. Specialist content review is pending.

More information: [regulalearn.com](https://regulalearn.com)

### Ambient Engine

A Linux desktop audio application focused on ambient audio generation and original audio-engine development, built with C++ and JUCE for Linux.

### NetAetra

A security-focused software project exploring structured assessment and defensive tooling.
