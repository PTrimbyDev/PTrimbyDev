# Paul Trimby

**Independent software developer building practical desktop applications for AI governance, privacy, regulatory learning and defensive security.**

I design, build and test software from concept to implementation, with an emphasis on practical workflows, clear interfaces, maintainable engineering and privacy-conscious design. My wider interests include audio software, data analysis and machine learning.

## Current Projects

### Praesera

A local-first desktop workspace for operational AI governance, risk and compliance.

Praesera brings together AI systems, risks, controls, evidence, assessments and actions, supported by an activity history. It is designed to help professionals maintain traceable governance records, connect related information and manage ongoing governance and compliance work.

**Technologies:** React, TypeScript, Tauri, Rust and SQLite.

*Status: Private development, pre-release. Public information is limited to selected product details.*

### GovernanceWatch

A desktop application for collecting, reviewing and analysing AI governance news and developments from official sources.

GovernanceWatch supports relevance assessment, structured analysis and drafting, with human review built into the process before anything is published externally.

**Technologies:** React, TypeScript, Tauri, Rust and SQLite.

### RegulaLearn

A desktop-first regulatory decision-training application built around fictional workplace scenarios, learner choices, reasoned feedback and references to authoritative sources.

The current **Privacy & Data Protection evaluation build** contains 10 learner-facing scenarios. Progress is stored locally, and specialist content review remains pending.

**Technologies:** React, TypeScript, Tauri and Rust.

[Visit RegulaLearn](https://regulalearn.com/)

### NetAetra

A VB.NET defensive security project focused on network assessment, including port scanning, TLS certificate inspection and structured scan results.

The development foundation includes automated builds, automated tests and NuGet dependency vulnerability auditing.

**Technologies:** VB.NET, .NET 10 and C# for testing.

### Ambient Engine

A Linux desktop audio application exploring ambient sound generation and original audio-engine development.

**Technologies:** C++ and JUCE.

## Development Approach

I use AI-assisted development as part of a broader engineering workflow that includes version control, testing, code review and verification. I review generated code, make implementation decisions and take responsibility for the resulting software.

I favour local-first architectures and privacy-conscious design where they suit the application. I also distinguish private product development from selected public projects, sharing work where it is appropriate without treating every project as a public release.
