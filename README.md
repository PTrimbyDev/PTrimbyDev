## Current Projects

### RegulaLearn

**RegulaLearn** is a desktop-first regulatory decision-training application built around fictional workplace scenarios, learner decisions, reasoned feedback and traceability to authoritative sources.

The current module is **Privacy & Data Protection**. The current **Evaluation build** contains 10 learner-facing scenarios and is built with React, TypeScript, Tauri and Rust. Learner progress is stored locally. Specialist content review is pending.

More information: [regulalearn.com](https://regulalearn.com)

### Ambient Engine

A Linux desktop audio application focused on ambient audio generation and original audio-engine development, built with C++ and JUCE for Linux.

### NetAetra
